# 行为规格文档目录（docs/specs/）

本目录存放 NeoManager 的**文字版 GUI 行为规格**，是实现唯一依据（净室原则）。

## 为什么需要行为规格

Neo 对标的功能形态来自对同类工具的日常使用观察。为规避著作权风险，
实现过程与任何闭源软件的反编译产物**完全隔离**：

- ✅ 允许：正常运行观察 → 用自己的话手写「做什么」级别的行为规格（本目录）
- ✅ 允许：借鉴功能概念与交互思想（思想不受著作权保护）
- ❌ 禁止：反编译产物进入仓库或任何代码路径；复刻 UI 美术/图标/文案

## 规格文档规范

1. 只描述**做什么**（行为、状态、流程），不描述**怎么做**（实现细节属于代码）；
2. 命名：`<领域>-<行为>.md`，如 `filemanager-context-menu.md`（文件管理-长按菜单）；
3. 结构建议：入口与触发方式 → 界面元素清单 → 交互流程 → 边界与异常；
4. 不收录任何截图/录屏/贴图（观察过程产物仅存于私有环境，15 天自动过期）。
