# 规格来源与净室合规声明

本目录所有规格文档均为**纯文字行为规格**，来源仅限两类：

1. NeoManager 项目成员对 MT 管理器（官方版/mod 版）**正常运行时的界面观察**，
   用自己的话转写为「做什么」级别的描述；
2. MT 官网公开文档（mt.cc/guide、mt.cc/vip、mt.cc/releases）的文字内容转写。

## 红线（见项目蓝图 5.1）

- 不收录 MT 截图/美术资源/图标；
- 不反编译 MT 后按其代码结构实现；实现只对本文档规格负责；
- 规格中出现的界面文案为观察记录，NeoManager 实现时使用自己的文案与视觉方案。

## 版本对照备注（2026-10-10 观察）

- 观察主体为 MT 管理器官方 2.26.10；
- 其中「Arsc 编辑器++」与「APK 共存」两段来自**旧版本演示**
  （前者为官方 VIP 付费功能，后者因账号登录条件使用旧版操作），规格以功能概念为准；
- XML 编辑相关行为以官网公开文档（guide/reverse/xml）描述为准；
- 官方更新记录快照存于项目外部资料库（不入库），最新版参考 v2.26.10（2026-10-09）。
