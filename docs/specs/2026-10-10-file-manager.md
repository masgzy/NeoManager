# 文件管理行为规格（源自对 MT 2.26.10 的观察，纯文字转写）

> 日期：2026-10-10。本文档只描述「做什么」，不描述「怎么做」。
> NeoManager 实现时使用自己的文案、图标、布局与交互视觉方案。

## 1. 双窗口主界面

- 恒定左右两个文件窗格，各自独立导航；中间分隔条可拖拽调节宽度，支持双击复位。
- 每个窗格结构自上而下：路径/面包屑区、文件列表、底部快捷栏（前进/后退/上级/新建）。
- 全局菜单（窗格内右上角）提供：刷新、搜索、全选、过滤、排序方式、显示/隐藏文件开关、
  添加书签、设为首页、交换窗口（左右窗格内容互换）、设置、退出。
- 侧边抽屉：书签区（可分组）、历史记录区、工具区（回收站、已安装应用、文本编辑器等入口）。
- 首页可为「存储列表」：展示内部存储、外置存储、分组目录，支持新建窗口、调整布局。

## 2. 排序与过滤

- 排序键：名称 / 大小 / 修改时间 / 扩展名；可勾选「仅限当前目录生效」「逆序排序」。
- 目录恒排在文件之前（与排序键无关）。
- 过滤：按文件名包含文本过滤当前列表；支持仅目录 / 仅文件两种限制。
- 显示选项：显示隐藏文件（点前缀）、显示系统隐藏文件，各自独立开关并可编辑规则。

## 3. 条目操作（长按菜单）

- 长按条目弹出操作菜单，基本项：打开方式、复制（子菜单：到另一窗格/自定义目标）、
  移动（子菜单同上）、重命名、删除、压缩、解压（压缩包条目）、属性、分享、添加书签、工具。
- 「工具」子菜单（新版新增）：文件更新（较新版本覆盖）、文件并存（双份保留）、
  交换文件名、创建软链接、创建快捷方式、导出文件列表（含/不含子目录）。
- 多选模式：全选/反选后底部出现批量操作栏（复制/移动/删除/压缩/分享/属性），
  批量删除与卸载有二次确认。

## 4. 属性对话框

- 基本字段：名称、所在目录、类型、大小（人类可读 + 原始字节）、修改时间（可编辑）、
  权限（九宫格 rwx 编辑器 + 特殊位 setuid/setgid/sticky + 符号串显示）、
  所有者/所有组（提供候选列表选择）、链接指向（符号链接条目）、
  APK 条目额外显示包名/版本/最小 SDK 等（Phase 2 接入）。
- 校验和页：MD5 / SHA1 / SHA256 / CRC32 逐项计算并显示，支持复制、大小写切换。

## 5. 新建与压缩

- 新建：文件夹 / 文件（输入名称）。
- 创建压缩文件对话框：文件名、格式（zip / 7z / tar / tar.gz / tar.xz / tar.zst / tar.bz2 等）、
  压缩级别、密码（可选）、分卷大小（无 / 10M / 25M / 50M / 100M / 自定义）、
  压缩后删除源文件开关。zip 家族支持「转入压缩包浏览」。
- 解压对话框：解压到当前目录 / 新建同名文件夹；可选解压后删除源文件。

## 6. 搜索

- 简单搜索：文件名包含文本，可选「搜索子目录」。
- 高级搜索：区分大小写、正则表达式、大小范围、时间范围、仅目录/仅文件。

## 7. 书签与历史

- 书签：任意目录可添加，侧边抽屉展示，支持分组与排序置顶；
  左右窗格手势区可区分左右侧书签（新版支持关闭）。
- 历史记录：记录浏览过的目录，可在侧边抽屉查看/清除。

## 8. 回收站

- 删除操作可先移入回收站（内部存储根目录约定目录），支持自定义回收站目录。
- 自动清理策略：禁用 / 1 / 3 / 7 / 14 / 30 / 60 / 90 天。

## 9. Root / Shizuku / Shell

- 设置页提供：请求 Root 权限、请求 Shell(adb) 权限（Shizuku）、自定义 su 命令。
- 无权限访问目录时自动降级尝试更高权限后端；状态可在设置页探测。
- 已安装应用管理（独立页面）：用户应用/系统应用分页、应用详情（包名/版本/大小/
  安装时间/数据目录/APK 路径/UID）、卸载、APK 提取到下载目录、按名称/包名/大小/
  安装时间排序。

## 10. 其他日常功能（版本规划备忘）

- 远程管理：本机起 HTTP/FTP 服务供局域网访问设备文件（Neo 列入 Phase 5，非本次）。
- 文件分割（按大小/数量/名称长度）、文件加密、校验、软链接——按需排期。
- MCP 服务（AI 工具接口）——与「全本地化无联网」原则冲突，Neo 默认不做。
