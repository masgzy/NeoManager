# 文本编辑器与逆向工具行为规格（纯文字转写）

> 日期：2026-10-10。来源：对 MT 2.26.10 的运行观察（编辑器部分为官方新版行为；
> Arsc 编辑器++ 与 APK 共存两段为旧版演示）+ 官网公开文档。
> NeoManager 实现时使用自己的文案与视觉方案。

## 1. 文本编辑器（Phase 1 ② 范围用 ★ 标注）

★ 打开/编辑/保存文本文件；未保存关闭时提示「是否保存」。
★ 查找/替换（区分大小写、正则、范围切换），查找结果计数与上一个/下一个导航。
★ 显示行号；自动换行开关；字符集（编码）读取与「指定保存编码」另存。
★ 大文件保护：超大文件提示并降级（关闭高亮等），避免 OOM。
- 换行符选择与转换（CRLF / CR / LF）。
- 统计对话框：字符数、单词数、非空白、中文个数、总行数。
- 行操作二级菜单：复制行/剪切行/删除行/清空行/替换行/重复行/转大写/转小写/增减缩进。
- 快捷功能栏：可自定义按钮（插入文本类/执行功能类），支持导入导出配置。
- 语法高亮 grammar 管理（内置多语言方案，可下载扩展）。
- 双窗编辑模式（同屏两个编辑视图对照）。
- 多标签与「保存全部」。

## 2. Dex 编辑器++（Phase 3 规格，先记录不实现）

- 入口：dex 文件「打开方式 → Dex 编辑器++」；顶部页签：类浏览/最近/搜索/书签。
- 类树按包层级展开；类视图以 smali 语法展示与编辑，语法着色区分
  类/字段/方法/行号/调用。
- 搜索：类名/方法名/字段名/字符串常量/代码文本；支持正则与大小写开关。
- 字符串常量池：全量字符串列表 + 过滤 + 批量替换。
- 转为 Java：多引擎可选（Jadx 全家/FernFlower/VineFlower/Procyon/CFR 等）。
- 转出：Jar（整 dex）、Smali 文件。
- 多文件工程：多个 dex 同时打开，保存为工程/备份/保存全部。
- Dex 修复：恢复非法 op、NOP 策略可配、逐 dex 处理。
- DEX 字符串解密：指定需解密的类与算法。
- Dex 属性：版本/字符串数/类型数/字段数/原型数/方法数统计。
- 查找引用：方法/字段/类/常量的交叉引用列表。
- **复制集成片段（新版功能，Neo 需求已确认）**：对任意方法/字段/类一键复制
  Frida hook 片段或 Xposed hook 片段到剪贴板（含类名/方法签名/参数重载枚举）。
- smali 指令速查手册（离线内置）。

## 3. Arsc 编辑器++（Phase 4 规格；观察段来自旧版演示）

- 入口：resources.arsc「打开方式 → Arsc 编辑器++」（官方为 VIP 功能）。
- 类型树：按包 → 资源类型（anim/array/attr/bool/color/dimen/drawable/id/integer/
  interpolator/layout/menu/mipmap/plurals/raw/string/style/xml/package-info）逐级浏览。
- 条目以 XML 片段形式展示与编辑（如 string 条目呈现为 <string name="xx">值</string>），
  支持直接改值/改名。
- 多配置变体：同一资源 ID 在不同配置限定符（zh-rCN/en-rGB/…）下的值并列查看与编辑。
- ID 定位：按资源 ID 跳转/搜索（字符串/整数/十六进制）。
- 字符串常量池：全局字符串池浏览、搜索（内容/类型：字符串/整数/十六进制）。
- 属性页：包名/条目数/字符串池统计/类型数等元信息。
- 集成翻译模式：词条级多语言批量翻译视图。

## 4. APK 工具（Phase 2 范围 = 签名 + 信息；其余记录）

★ APK 签名：方案组合选择（V1+V2+V3 / V1+V2 / V1+V3 / V1 / V2+V3…）；
  签名密钥选择；V1 签名数据文件名可自定义。
★ 签名密钥管理：已导入密钥列表、新建密钥（别名/密码/有效期/主体字段）、
  默认密钥标记、密钥文件存放目录可配置。
★ APK 信息：属性卡（包名/版本号/版本名/大小/目标与最小 SDK/数据目录/APK 路径/UID 等）。
- APK 优化（性能优先/大小优先/慢压缩）、XML 翻译模式、XML 批量替换、APK 共存、
  RES 混淆/反混淆/精简、DEX 重新划分（65536 方法上限拆分）、注入日志记录、
  注入文件选择器、去除签名校验、数据复用优化 —— 均列入后续版本评估；
  其中「去除签名校验」类对抗功能按蓝图 B-1 分级架构另行评审。

## 5. 已安装应用（Phase 2）

- 用户应用/系统应用分页；搜索；排序（名称/包名/包大小/首次安装时间/最后更新时间）。
- 详情卡：图标、包名、版本、大小、安装/更新时间、数据目录、APK 路径、UID、来源。
- 操作：卸载（二次确认）、提取 APK 到本地、查看安装包（跳转 APK 所在目录）。
- 安装流设置：安装来源（默认/Google Play/自定义安装器）、APK 安装二次确认、
  安装后删除安装包、Shizuku/Root 静默安装通道（有权限时）。

## 6. 远程管理与平台能力（记录，暂不排期）

- 远程管理：HTTP/FTP 服务开关、根路径、端口、账号密码、会话有效期、设备管理。
- 网络存储：FTP/FTPS/SFTP/SMB/WebDav（官方对部分标注 VIP）。
- 终端模拟器（需扩展包，Neo 采用 Termux:terminal GPL 路线，Phase 5）。
- MCP 服务（AI 工具接口）：与全本地化原则冲突，Neo 默认不提供。
